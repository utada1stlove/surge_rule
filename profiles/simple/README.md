# Surge Simple 权重

`Smart` 使用 `smart` 策略组，数值越小优先级越高。权重采用乘法模型：

```text
最终权重 = 国家倍率 × 所有特殊标签倍率
```

没有命中标签时，倍率为 `1.0`。

## 国家标签

| 标签 | 倍率 |
| --- | ---: |
| `HK` | `2.2` |
| `CTM` | `2.2` |
| `JP` | `0.8` |
| `SG` | `0.8` |
| `US` | `0.4` |

## 特殊标签

| 标签 | 倍率 |
| --- | ---: |
| `snell` | `0.8` |
| `tx` | `0.7` |
| `vol` | `0.8` |
| `hy2` | `0.8` |
| `aws` | `0.75` |
| `cft` | `0.75` |
| `ixp` | `0.5` |

## 组合示例

| 节点标签 | 计算 | 最终权重 |
| --- | --- | ---: |
| `SG` | `0.8` | `0.8` |
| `SG TX` | `0.8 × 0.7` | `0.56` |
| `HK VOL` | `2.2 × 0.8` | `1.76` |
| `US IXP` | `0.4 × 0.5` | `0.2` |
| `SG TX VOL` | `0.8 × 0.7 × 0.8` | `0.448` |
| `HK SNELL AWS` | `2.2 × 0.8 × 0.75` | `1.32` |
| `SG TX VOL IXP` | `0.8 × 0.7 × 0.8 × 0.5` | `0.224` |

节点名应按以下顺序排列标签，便于配置中的组合规则匹配：

```text
国家 → snell → tx → vol → hy2 → aws/cft → ixp
```

例如：

```text
SG [tx] [vol] [ixp]
HK [snell] [aws]
US [hy2]
```

## policy-priority 边界

`policy-priority` 按 Surge 的首条匹配规则工作，不会把多条规则的倍率自动相乘。因此配置将组合的乘积直接写入规则，并按“多标签组合 → 单标签 → 国家基准 → `.*:1.0`”排列，避免通用规则提前截断组合。

当前组合规则支持国家标签 `HK`/`CTM`、`JP`/`SG`、`US` 与 `snell`、`tx`、`vol`、`hy2`、`aws`/`cft`、`ixp` 的固定顺序组合；无国家的特殊标签也有独立兜底规则。由于 Surge 的 `policy-priority` 不提供可复用的乘法函数，节点标签必须按上面的固定顺序书写；任意顺序不会被当作同一组合，最终会回退到后续可匹配规则或 `1.0`。

例如 `SG [tx] [vol] [ixp]` 命中 `0.8 × 0.7 × 0.8 × 0.5 = 0.224`，`HK [snell] [aws]` 命中 `2.2 × 0.8 × 0.75 = 1.32`。`aws` 与 `cft` 共享一个特殊标签槽位，单个节点命中其中任一名称时倍率为 `0.75`。
