# Web Research Capture

Run `scripts/capture_webpage.py URL output-directory`. Preserve the source URL,
retrieval time, page title, and extraction limitations beside the Markdown.

The capture is evidence, not proof that the page is current or authoritative.
Record publication dates separately when available. Login walls, client-rendered
content, or failed requests must be stated rather than replaced with guesses.
