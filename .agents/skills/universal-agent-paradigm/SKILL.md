# Universal Agent Paradigm

Keep ordinary work direct. For a task with multiple artifacts, external evidence,
material risk, or publication, create a live CLI plan before material work.

1. Identify final artifacts, build tools, output paths, validation, and cleanup.
2. Read project `AGENTS.md` and route to the smallest matching skill.
3. Keep one plan child active; record scope, evidence, cutoff, artifact, and acceptance check.
4. Separate source facts, translations, inferences, and decisions.
5. Use an independent read-only agent only for material claims, risky changes, or unresolved uncertainty.
6. Run deterministic checks before narrative review. Inspect outputs, not just command exit codes.
7. Clean build intermediates, reconcile the live plan, then commit or publish only completed work.

For ambiguous, irreversible, or architecture-changing requests, challenge the
assumption once with evidence, then follow the user's decision. Do not apply
this extra review to simple, reversible tasks.
