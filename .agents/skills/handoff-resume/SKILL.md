# Handoff Resume

Record the active outcome, live-plan state, data cutoff, files changed,
validation already run, unresolved questions, and exact next action. On resume,
verify repository state and artifact existence before repeating any work.

Do not summarize secrets, credentials, or raw transcripts. A handoff is an audit
and recovery aid; it does not replace the live CLI plan for active work.
