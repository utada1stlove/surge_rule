## 后续采用原则

- 先以最小可用配置验证功能，再选择性引入策略组、规则和模块；
- 不直接导入来源不明或未经审查的远程脚本与模块；
- 不将节点订阅、密码、Token、私钥或 Controller 密钥写入公开文件；
- 变更前保留当前可用 Profile，逐项应用并通过 Surge 请求列表确认实际命中。
